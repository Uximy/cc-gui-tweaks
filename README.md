# CC GUI Tweaks

Плагин для IDE JetBrains, который добавляет модули в чат плагина
[CC GUI (Claude, Codex and More)](https://plugins.jetbrains.com/) от MossX. Сам CC GUI не меняется:
плагин находит его страницу во встроенном браузере IDE и встраивается в неё скриптом. Поэтому обновления
CC GUI ничего не ломают.

Автор: [Uximy](https://github.com/Uximy) · [himitsu-fm.online](https://himitsu-fm.online/)

## Что умеет

Каждый модуль включается отдельно и по умолчанию выключен. Выбор сохраняется между запусками IDE.
Настройки находятся внутри настроек CC GUI, в разделе **CC GUI Tweaks**, на вкладках
«Spotify / Лимиты / Производительность / О плагине».

| Модуль | Что делает |
|---|---|
| **Spotify** | Мини-плеер над полем ввода чата: трек, обложка (по клику увеличивается), пауза и переключение треков, перемотка по полоске прогресса, громкость. Два размера. Крестик сворачивает плеер в значок Spotify. |
| Очередь и плейлист | Список «дальше играет» и плейлист текущего трека через Spotify Web API (нужен свой Client ID, инструкция есть на вкладке). Чтобы включать трек из очереди кликом, нужен Spotify Premium. |
| Текст песни | Кнопка-микрофон в плеере. Текст берётся из открытой базы [LRCLIB](https://lrclib.net), текущая строка подсвечена и сама прокручивается, клик по строке перематывает к ней. |
| **Лимиты Claude** | Полоска расхода 5-часового окна и недельных лимитов, те же цифры, что `/usage` в Claude Code. Показывает время сброса и лимиты по моделям. |
| **Производительность** | Останавливает бесконечные CSS-анимации и размытие чата. От них встроенный браузер рисует кадры без остановки. |
| Встроенный браузер IDE | Переключатели в реестре IDE: частота кадров, браузер в отдельном процессе, аппаратное ускорение. Есть кнопка «Вернуть как было». |
| Журнал лагов | Записывает долгие кадры чата (и какой скрипт их вызвал), зависания окна IDE и раз в минуту загрузку процессора и памяти. «Выгрузить логи» собирает zip для разбора. |

## Требования

- Windows 10/11. Плеер Spotify работает через медиа-сессию Windows, а громкость через микшер Windows.
- IDE JetBrains 2024.3 или новее (build 243+). Проверено на WebStorm 2026.3.
- Установленный плагин CC GUI.
- Для лимитов: Claude Code, в который вошли через подписку Claude (Pro/Max).
- Для плеера: приложение Spotify для компьютера.

## Установка

Готовый `cc-gui-tweaks.jar` лежит в Releases репозитория (или собирается командой из раздела ниже).

1. В IDE откройте **File → Settings → Plugins → ⚙ → Install Plugin from Disk…** и выберите `cc-gui-tweaks.jar`.
2. Откройте окно CC GUI, затем его настройки (шестерёнка). В меню слева появится **CC GUI Tweaks**: включите нужные модули там.

Подробная инструкция для пользователей, с ответами на частые проблемы: [`dist/Как установить CC GUI Tweaks.txt`](dist/Как%20установить%20CC%20GUI%20Tweaks.txt).

## Сборка

Gradle не нужен. `build.py` компилирует исходники `javac` из JBR установленной IDE, используя её же библиотеки.

```bash
# собрать build/cc-gui-tweaks.jar
python -I build.py

# собрать и сразу поставить в IDE (папка конфига IDE)
python -I build.py install "$APPDATA/JetBrains/WebStorm2026.3"
```

- Путь к IDE, с библиотеками которой идёт компиляция, задаётся переменной `IDE_HOME`. По умолчанию это `C:\Program Files\JetBrains\WebStorm 2024.3.2.1`.
- Каждая сборка получает новую версию вида `1.0.ггММддччммсс`.
- Если IDE запущена, `install` обновляет плагин **без перезапуска**: JAR кладётся в `<конфиг>/cc-gui-tweaks/update/`, а работающая версия сама себя перезагружает (см. [`Updater.java`](src/local/ccguitweaks/Updater.java)). Как это прошло, видно в `idea.log` по строкам `cc-gui-tweaks:`.

## Структура проекта

```
build.py                         сборка и установка (без Gradle)
resources/
  META-INF/plugin.xml            описание плагина и подписки на события IDE
  cc-gui-tweaks/tweaks.js        всё, что видно на странице: плеер, лимиты, панель настроек, журнал кадров
  cc-gui-tweaks/helper.ps1       локальный HTTP-хелпер: медиа-сессия Spotify и громкость в микшере Windows
src/local/ccguitweaks/
  Starter.java                   запуск/остановка при старте IDE и горячей перезагрузке
  Tweaks.java                    поиск браузеров CC GUI, внедрение скрипта, обмен сообщениями
  Settings.java                  настройки модулей (сохраняются в IDE)
  SpotifyModule.java             плеер: запуск helper.ps1 и опрос его
  SpotifyWeb.java                вход в Spotify (OAuth PKCE), очередь и плейлист
  Lyrics.java                    тексты песен из LRCLIB
  LimitsModule.java              лимиты Claude (api.anthropic.com/api/oauth/usage)
  RegistryTweaks.java            ключи реестра встроенного браузера IDE
  PerfJournal.java               журнал лагов и выгрузка логов в zip
  Updater.java                   горячая замена плагина без перезапуска IDE
dist/                            файлы для раздачи: инструкция (и jar после сборки)
docs/ARCHITECTURE.md             как всё устроено внутри
```

Как всё работает внутри, по шагам: **[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)**.

## Приватность

- **Claude.** OAuth-токен читается из `~/.claude/.credentials.json` при каждом запросе и уходит только на `api.anthropic.com`. Плагин его никуда не сохраняет и не пишет в лог.
- **Spotify.** Refresh-токен хранится в хранилище паролей IDE (PasswordSafe), access-токен только в памяти. Запросы уходят только на `accounts.spotify.com` и `api.spotify.com`.
- **LRCLIB.** Туда уходят только название, исполнитель, альбом и длительность трека, и только когда открыта панель текста. User-Agent без личных данных.
- **Журнал лагов.** Хранится только на компьютере. В выгружаемом zip токены вычищены, а путь к профилю пользователя заменён на `~`.
